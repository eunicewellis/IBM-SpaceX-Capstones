# Final submission checklist

- [ ] API notebook runs and raw source/output provenance is documented.
- [ ] Web-scraping notebook identifies the correct table and explains cleaning.
- [ ] Wrangling notebook records missingness, duplicates, target definition and output shape.
- [ ] SQL notebook is run; each task shows query output and short interpretation.
- [ ] EDA visualization notebook is run and all required plots appear.
- [ ] Folium map is rendered and `launch_site_map.html` is generated.
- [ ] Dash app starts; capture screenshot showing dropdown, pie chart, slider and scatter plot.
- [ ] ML notebook is run from top to bottom; compare Logistic Regression, SVM, Decision Tree and KNN. Record test metrics and confusion matrix from this run.
- [ ] Final report PDF includes real outputs/screenshots and uses the correct GitHub URL.
- [ ] Verify repository is public and every expected file is visible before submitting.
